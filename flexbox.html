O que é Flexbox?

Flexbox é um recurso do CSS usado para organizar elementos dentro de um contêiner. Ele facilita o alinhamento, a distribuição dos espaços e a adaptação dos elementos a diferentes tamanhos de tela.

É um layout unidimensional: organiza os itens principalmente em uma linha ou em uma coluna.

  • display: flex; ativa o Flexbox no contêiner;
  • flex-direction define a direção dos itens;
  • justify-content distribui os itens no eixo principal;
  • align-items alinha os itens no eixo transversal;
  • gap define o espaço entre os itens;
  • flex-wrap permite que os itens quebrem para outra linha.

1. Ativando o Flexbox

O contêiner é o elemento pai. Os itens flexíveis são os elementos que ficam dentro dele. Ao aplicar display: flex; no pai, os filhos passam a ser organizados pelo Flexbox.

.container {
  display: flex;
  gap: 12px;
}

3. Alinhamento e distribuição

justify-content organiza os itens no eixo principal. Já align-items alinha os itens no eixo transversal. Com gap, controlamos a distância entre eles.

Um
Dois
Três
.container {
  display: flex;
  justify-content: space-around;
  align-items: center;
  gap: 12px;
}

Outros valores comuns de justify-content são flex-start, center, flex-end, space-between e space-evenly.

5. Propriedades dos itens

Além das propriedades do contêiner, os próprios itens podem ser ajustados. A propriedade flex-grow, por exemplo, permite que um item cresça para ocupar o espaço livre disponível.

Normal
Cresce
Normal
.item {
  flex-grow: 1;
}

Outras propriedades úteis são flex-shrink (controla a redução), flex-basis (tamanho inicial) e align-self (alinhamento individual de um item).

Quando usar Flexbox?

  • Para alinhar itens de um menu;
  • Para centralizar conteúdo horizontal e verticalmente;
  • Para distribuir botões ou cartões em uma linha;
  • Para organizar elementos em coluna;
  • Para adaptar grupos de itens a telas menores.

Atividade prática

Crie um contêiner com três itens. Teste flex-direction: column;, depois troque para row. Experimente também justify-content: center; e flex-wrap: wrap;.
