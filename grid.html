O que é CSS Grid?

CSS Grid é um sistema de layout que organiza os elementos em uma grade formada por linhas e colunas. Ele permite controlar as duas dimensões ao mesmo tempo: horizontal e vertical.

Por isso, o Grid é considerado bidimensional. É muito útil para organizar páginas, galerias de imagens, painéis e conjuntos de cartões.

  • display: grid; ativa o Grid no contêiner;
  • grid-template-columns define as colunas;
  • grid-template-rows define as linhas;
  • gap define o espaço entre linhas e colunas;
  • grid-column e grid-row permitem ocupar mais de uma coluna ou linha;
  • fr representa uma fração do espaço disponível.

1. Criando colunas

A propriedade grid-template-columns determina quantas colunas existem e qual é o tamanho de cada uma. Neste exemplo, temos três colunas de tamanhos iguais.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
}

A unidade fr divide o espaço disponível em frações. Também podemos usar medidas como 200px ou combinações como 200px 1fr 1fr.

2. Organizando linhas e colunas

O Grid posiciona os itens em células. Quando as colunas ficam cheias, os próximos itens passam para a linha seguinte automaticamente.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

repeat(3, 1fr) é uma forma curta de criar três colunas iguais.

3. Controlando o tamanho das linhas

Com grid-template-rows, podemos definir a altura das linhas. Neste exemplo, a primeira linha é maior que a segunda.

.container {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  grid-template-rows: 100px 60px;
  gap: 12px;
}

4. Um item ocupando mais espaço

Com grid-column, um item pode ocupar mais de uma coluna. Isso ajuda a criar áreas maiores dentro da grade.

5. Grid responsivo

Para que os cartões se ajustem ao tamanho da tela, podemos combinar repeat(), auto-fit e minmax(). Assim, o navegador cria a quantidade de colunas que couber no espaço disponível.

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
  gap: 12px;
}

Quando usar Grid?

  • Para montar o layout geral de uma página;
  • Para organizar galerias de imagens;
  • Para criar painéis com linhas e colunas;
  • Para alinhar cartões em uma grade;
  • Para construir layouts responsivos.

Atividade prática

Crie uma grade com três colunas e seis itens. Depois, altere para duas colunas, modifique o gap e faça um dos itens ocupar duas colunas usando grid-column: span 2;.
